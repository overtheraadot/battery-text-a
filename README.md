A make.fun entry for "The Battery's Last Text to Its Charger" — one line, at most 200 characters: the phone battery's final message to the charger it waited for all day.

## The entry

> 1% left. You were 'five more minutes' away at breakfast, lunch, and dinner, so I'm dumping you by text. Don't text back — I won't be alive to read it.

150 characters, 30 words, 1 line. A breakup text, not a sad goodbye: the battery waited all day while the charger kept promising it was "just five more minutes" away, so it dumps the charger by text — and forbids a reply, because it will be dead before it could read one.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
